# Known HTTP header names.
#
# This file is the single source of truth for the generated header matcher in
# ../Generated/KnownHeaders.g.cs. Edit this file, never the generated one, then run
# ../../../tools/generate-known-headers.sh and commit both.
#
# Format
#   One header per line, in its canonical casing.
#   Blank lines and lines starting with '#' are ignored.
#   Trailing '#' comments are not supported - a '#' is only a comment at the start of a line.
#   "Name = EnumMember" overrides the derived enum member name.
#
# The enum member name is derived by stripping '-' and '.' and keeping the casing written
# here, so "Content-Length" becomes ContentLength and "TE" stays TE. Override only where
# that reads badly.
#
# The canonical casing matters at runtime: in the default HeaderNameMode.AsReceived, a
# header whose bytes match this spelling exactly is reported using the cached instance
# below instead of a freshly allocated string. Spell these the way senders actually send
# them.
#
# Every name must be a valid RFC 9110 token. The generator rejects anything else, because
# the matcher's case-folding is only exact over the token byte set.
